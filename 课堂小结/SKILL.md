# 课堂小结 Skill

为火箭2班的学科课堂生成标准化的小结文档，以 .docx 格式保存在对应学科目录下。

## 核心工作流程

### 第一步：获取日期

自动获取当天日期，格式为 `M.DD`（如 7 月 14 日 → 7.14）。如果当天日期与用户所说的日期不一致（如补写之前的小结），以用户说的日期为准。

### 第二步：收集信息

向用户询问以下信息（如果用户一次性提供了全部信息则跳过）：

1. **学科** — 如"数学"或"物理"
2. **章节** — 本节课的章节标题
3. **知识点** — 本节课涵盖的核心知识点

如果用户输入了不在映射表中的学科，查阅 `references/subjects.md` 确认路径。如果学科也不在映射表中，与用户确认保存路径。

### 第三步：生成内容

根据用户提供的章节和知识点，生成两部分内容。

文档中两个章节标题固定为 `1️⃣ 授课内容` 和 `2️⃣ 学习要求`。

**授课内容（3 条）：**
- 对知识点的系统化梳理，每条描述一个核心教学内容
- 用词专业、准确，符合学科特点
- 每条之间要有逻辑递进关系：概念引入 → 方法/性质 → 综合应用

**学习要求（3 条），每条必须针对一个关键能力维度：**
- 第①条 — **概念理解能力**：理解核心定义、概念之间的内在联系
- 第②条 — **运算/方法掌握能力**：掌握相关运算规则或方法，能灵活运用
- 第③条 — **综合应用/迁移能力**：能将所学知识应用到新情境，解决综合问题

用词要求：专业、清晰、像备课组存档文档。不使用口语化表达。

### 第四步：直接生成文档

完成 3 条授课内容和 3 条学习要求后，直接调用 `scripts/create_docx.py` 生成 .docx 文件；不要展示草稿、不要请求用户确认。仅当用户明确要求修改已生成内容时，再按要求修改并重新导出文档。

```bash
python "C:\Users\Lenovo\.claude\skills\课堂小结\scripts\create_docx.py" \
  --title "火箭2班[学科]小结[日期]" \
  --content '["内容1", "内容2", "内容3"]' \
  --requirements '["要求1", "要求2", "要求3"]' \
  --output "[保存路径]\课堂小结[MMDD].docx"
```

**保存路径**查阅 `references/subjects.md` 获取。文件名格式固定为 `课堂小结MMDD.docx`（如 `课堂小结0714.docx`）。

如果目标路径已存在同名文件，需要询问用户是否覆盖。

生成 `.docx` 后无需打开、渲染或检查文档；直接向用户交付生成的文件。

## 学科路径映射

详细映射表在 `references/subjects.md`。需要时读取该文件确认路径。

## 注意事项

- 班级名固定为「火箭2班」
- 章节标题固定为「1️⃣ 授课内容」和「2️⃣ 学习要求」，emoji 后保留一个空格
- 授课内容和学习要求各固定为 3 条
- 学习要求每条针对一个关键能力维度（概念理解 / 方法掌握 / 综合应用）
- 语气必须专业、正式，避免口语化
- 完成内容后直接导出 Word，不展示草稿或等待确认
- 导出后无需进行文档检查；仅在用户明确提出修改时重新导出
- 如果用户对生成的内容不满意，按要求修改并重新导出
