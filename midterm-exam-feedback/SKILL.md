# 期中考试反馈

按“反馈表 → 三科试卷 → 草稿校验 → 写回”执行。处理数学（满分 150）、物理与化学（各满分 100）。

## 1. 收集与读取反馈表

首次仅要求用户提交或明确指定期中反馈 `.xlsx` 文件。不得同时索取试卷。

每次执行都先要求用户提交或明确指定本次要读取的反馈表。除非用户在当前对话中给出了确切文件路径、上传了文件，或明确确认复用先前指定的文件，否则不得扫描、搜索、猜测或自行选取用户电脑中的任何 Excel 文件；即使发现名称相近的历史表、样表或输出文件也不得读取。向用户复述将读取的完整路径，供其确认。

使用 `node scripts/patch_xlsx.mjs inspect <file.xlsx> <数学|物理|化学>` 分别检查三科工作表。每张表都必须有精确表头 `姓名`、`考试反馈`，及至少一个题型得分列；忽略 `序号`、`总分`、`考试分数` 等非题型列。保留学生行号、姓名、既有反馈和题型得分。

若只提供总分（如“考试分数”列），明确说明无法按题型写反馈，并要求用户补充题型得分表；不得从总分猜测题型完成情况。任一目标工作表或必需列缺失时停止，不修改文件。

先对三科都完成检查，确认学生分数均为数值；请假、缺考、空白及其他非数值成绩标记为跳过，后续保持其反馈单元格不变。

## 2. 收集并分析试卷

表格检查通过后，要求用户提供数学、物理、化学三份完整、清晰且题号可见的试卷（PDF、图片或 Word）。逐题阅读，建立每科“表头题型 → 题号范围/题目 → 知识点 → 该题型满分”的映射。

题型名称无法匹配、试卷不完整或题型满分汇总不等于学科满分时，列出具体学科与问题并停止写入。不得依据往期试卷、题库或截图中的泛化描述补全。

### 已确认试卷配置

- 火箭2班数学期中试卷：`选填`满分 73 分，`大题`满分 77 分，合计 150 分。选填覆盖集合、命题与充分必要条件、函数概念与性质、基本不等式、二次函数及不等式、概率统计；大题覆盖集合运算、函数解析式与复合函数、指数和对数运算、奇偶性与单调性、函数不等式及不动点。
- 火箭2班物理期中试卷：`选填`满分 55 分，`实验题`满分 5 分，`计算题`满分 40 分，合计 100 分。选填覆盖质点、匀变速直线运动及图像、受力分析、摩擦力与弹簧、平衡和传送带；实验题考查弹簧力与伸长量关系、电火花计时器及纸带数据处理；计算题考查圆周运动、速度时间图像、匀变速直线运动、碰撞、弹簧平衡与加速度时间图像。
- 火箭2班化学期中试卷：`选择题`满分 45 分，`综合题`满分 55 分，合计 100 分。选择题覆盖离子方程式、氧化还原反应、物质性质与用途、离子检验、氯及氯水、物质分类和碳酸盐反应；综合题考查苏打水成分与反应、侯氏制碱、氯气制备与氧化还原、钠与水反应、碳酸盐热稳定性及实验装置分析。

## 3. 生成与润色反馈

对每位数值成绩学生的每个学科生成一条 40–55 个汉字的反馈：

- 依据题型得分率写完成情况：≥85%“掌握扎实”，70–84%“完成较好”，60–69%“基本掌握”，<60%“需加强”。
- 结合该题型试卷知识点，说明至少一项掌握情况，并给出一项明确、可执行的复习建议。
- 语言专业、清晰、面向学生；不得只报分数、编造知识点、使用贬损语言或泛泛鼓励。
- 同批次避免完全相同或仅替换同义词的反馈。即使学生处于相同完成等级，也要结合各题型得分率的相对高低，分别突出优势题型、薄弱题型、对应知识点或训练建议；连续学生不得使用相同句首、句式或建议动词。先做批量重复度检查，发现题型完成情况或表述过于雷同时，在内存中重写后再写入。

形成全批草稿后调用 `humanizer-zh` 一次进行批量润色。润色只能改善自然度与表达，不能改变题型表现、知识点、建议、字数或正式助教语气。润色后重新核对所有约束。

## 4. 写回与验证

仅在三科均已通过表格与试卷校验、所有草稿均合格后写入。覆盖三张工作表的 `考试反馈` 列中对应数值成绩学生；跳过行绝不写入。

将每学科更新编码为 base64url JSON 数组 `[{"row": 3, "text": "..."}]`，依次调用：

```powershell
node scripts/patch_xlsx.mjs write <file.xlsx> <学科> <base64url-json>
```

脚本直接替换目标工作表的目标单元格 XML，并验证其他工作簿部件未变、行高和列宽定义未变、写回文本与行号一致。不得使用整本工作簿导入导出、自动适应行列、格式化工具或会改动字体、字号、行高、列宽的库。

完成后报告各科写入人数、跳过人数，以及未处理原因（如有）。

## 失败处理

- 表格缺题型得分、表头不符或工作表缺失：停止并说明实际发现内容。
- 三科试卷未齐：说明缺少的学科，不写入。
- 题型与试卷无法一一对应、满分不符、文字不清：列出问题，等待补充。
- 任一反馈不在 40–55 汉字范围或缺少知识点/建议：在内存中修订，禁止写入不合格草稿。
